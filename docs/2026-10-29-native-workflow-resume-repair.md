Branch: `fix/native-workflow-resume-integrity`.

## Delivery contract

1. Bind checks to their result type, scope and actual execution; document status cannot certify tests or acceptance. Admit commands from accepted project checks or literal bound native sources.
2. Render per-layer native review packages, freeze an actual diff, enforce supported tool boundaries and wait for all reviewers.
3. Resume existing tickets using immutable collected artifacts or hash-verified legacy transcripts; preserve classification and prevent metadata-only restarts.
4. Resolve plan scope early, provide concrete recovery actions, preserve provider-specific routes.
5. Require per-finding patch and verification evidence for new reviews.
6. Compact host-facing output without breaking machine output; migrate active evidence explicitly; replay interrupted/no-VCS scenarios and run regression suites.

Each stage is committed and published independently. Historical completed Work is never recertified. CAO certifies evidence/process; native providers retain functional review and acceptance ownership. No duplicate CAO functional executor is introduced.
